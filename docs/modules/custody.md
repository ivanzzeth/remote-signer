# 密钥托管

**状态**:已实现。三种签名者(加密文件 / 助记词派生 / 明文),锁与自动锁,按身份
授予使用权。

**守的是**:[`prd.md`](../prd.md) 的 **G1**(私钥不离开这个服务)· **G5**(收回
立即生效)· **D1**(工作区是边界)。

**判据**:*有没有任何一条路径,能让私钥的字节离开这个进程?*

**关联**:[`../../SECURITY.md`](../../SECURITY.md) · [`identity.md`](identity.md)。

---

## 1. ⛔ 私钥只进不出

签名在进程内完成,接口只返回**签名结果**。没有任何接口返回私钥本身。

⚠️ 这条不能靠「没人写这样的接口」维持 —— 它要靠**私钥类型不出领域层**来维持。
一旦某个响应结构体里能放下它,迟早有人放。

## 2. 密钥材料在磁盘上,不在数据库里

加密文件、助记词、接口凭据都是磁盘文件;数据库里只有**公钥**和归属关系。

⭐ 这个划分有个好处:**换钥匙只是改数据库里的一列**,不动任何密钥材料。也因此
升级、迁移数据库都不会碰到私钥。

⚠️ 代价:密钥材料在**隐藏目录**里,浏览器的文件选择器默认看不见它。运维要把凭据
弄进界面时会找不到 —— 见 [`../incidents.md`](../incidents.md)。⛔ 解法不是把整个
数据目录搬到可见位置(那里还有数据库和签名密钥),而是给单个凭据一个导出出口。

## 3. 锁

签名者可以处于锁定状态,锁定时不能签。⚠️ 有**自动锁**:超时后自动回到锁定。

⛔ 锁是**运行时状态**,不是配置。收回一个身份的使用权必须立即生效(G5),不能
等到下次重启。

## 4. 使用权与归属是两回事

| | 说的是 |
|---|---|
| **归属** | 这个地址是谁的 |
| **使用权** | 除了归属者,还有谁能用它签 |

⚠️ 归属者的记录被外键约束保护 —— 删掉一个还持有签名者的身份会被拒绝。这是对的
(避免孤儿),但也意味着**「换人」不能走「删了重建」那条路**,见
[`identity.md`](identity.md)。

## 5. 运行环境的假设

⚠️ 进程内存里有解密后的私钥。启动时会检查交换分区并**告警** —— 开着交换分区意味着
私钥可能被写到磁盘上。⛔ 这是告警不是拦阻:阻止启动会让人去关掉这个检查,而不是去
关掉交换分区。

## 6. 重构时必须保住的

- [ ] 没有任何接口返回私钥;私钥类型不出领域层
- [ ] 密钥材料在磁盘,数据库只存公钥与归属
- [ ] 锁是运行时状态,收回立即生效
- [ ] 归属与使用权分开表达
- [ ] 外键保护:还持有签名者的身份不能被删
- [ ] **目标**:密钥材料也归工作区,跨工作区不可见(D1)
