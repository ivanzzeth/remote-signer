# 产品形态

**用途**:这个产品有**五种壳**,它们连的是同一个后端。说清每种壳**是什么、连谁、
身份存在哪**,以及切后端/切账号时用户看到什么。

**判据**:*同一个人同时管着两台 daemon(本机一台、服务器一台),他要切过去,得点几下?*
答不上来,就说明这份文档没写清楚。

**关联**:[`prd.md`](prd.md)(P1–P4 画像与 J1–J7 旅途) ·
[`../ARCHITECTURE.md`](../ARCHITECTURE.md) · [`modules/identity.md`](modules/identity.md)。

## 0. 五种壳,一个后端

```
        ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
        │  内嵌 Web UI │  │  独立 Web UI │  │     TUI      │  │  浏览器扩展   │
        │  daemon 自带 │  │  静态站/桌面 │  │  终端·已冻结 │  │  给 dApp 用   │
        └──────┬───────┘  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘
               │ 同源            │ 任意 URL        │ 任意 URL        │ 任意 URL
               └─────────────────┴────────┬────────┴─────────────────┘
                                          ▼
                                 ┌─────────────────┐
                                 │  daemon(后端)  │  ⛔ 私钥只在这里
                                 └─────────────────┘
```

⛔ **除内嵌 Web UI 外,每种壳都必须能连到任意指定的 URL。** 一个人可能同时管着本机
一台和服务器一台;把后端写死在客户端里,等于要求他为每台 daemon 装一份客户端。

⚠️ **内嵌 Web UI 是例外,而且必须是例外**:它由 daemon 自己提供,连的就是提供它的
那个源。让它去连别的后端意味着**它的来源和它的目标可以不一致** —— 那是一个钓鱼面。

---

## 1. 现状

| 壳 | 后端怎么定 | 能改吗 | 身份存在哪 |
|---|---|---|---|
| 内嵌 Web UI | 页面自己的源 | ⛔ 不该改(设计如此) | 浏览器本地,密码加密 |
| 独立 Web UI | 同上 —— **没有独立形态** | ❌ **缺** | — |
| TUI ⛔ **已冻结** | `-url`,默认 `https://localhost:8548` | ✅ | 每次启动重新给 |
| 浏览器扩展 | 构建期写进配置文件 | ❌ **要重新构建** | 由代理持有 |
| 桌面壳 | 端口**写死** | ❌ | 同内嵌 Web UI |

⛔ **四处缺口**:独立 Web UI 不存在;扩展改后端要重新构建;桌面壳端口写死;
**没有任何一种壳有 profile 概念** —— 切后端等于重新输一遍身份。

---

## 2. Profile:一份纯客户端的连接记录

**一个 profile = 连谁 + 用什么身份**。它**只存在客户端**,daemon 不知道它存在。

| 字段 | 说明 |
|---|---|
| 名字 | 用户自己起的,如「本机」「生产」 |
| 后端地址 | 指向哪台 daemon |
| 身份标识 | 用哪个身份登录 |
| 凭据 | ⛔ 加密后存;⚠️ **绝不明文** |
| 上次使用 | 排序用 |

⛔ **profile 之间的凭据必须互相隔离。** 切到「生产」时,「本机」的凭据不能在内存里
还是可用的 —— 否则一次误操作就打到了另一台机器上。

⚠️ **profile 里存的是「连谁」,不是「我是谁」。** 身份的权威在 daemon;profile 只是
一张便条,记着「上次我用这个身份连的这台」。便条过期(钥匙被吊销)时,**表现必须是
明确的拒绝而不是一串没权限**(PRD **N7**)。

### 切换 profile 时的界面

```
┌─────────────────────────────────────────────┐
│  ⬤ 生产 · signer.example.com      ▾        │ ← 常驻在顶栏,永远看得见当前连的是谁
├─────────────────────────────────────────────┤
│  ⬤ 生产        signer.example.com   admin   │
│  ○ 本机        127.0.0.1:8548       admin   │
│  ○ 测试网      10.0.0.7:8548        agent   │
│  ─────────────────────────────────────────  │
│  + 添加连接…                                │
│  ⚙ 管理连接…                                │
└─────────────────────────────────────────────┘
```

⛔ **当前连的是哪台,必须在任何时候都看得见**,不能藏进设置页。这个产品的每一次
操作都在花钱 —— 「我以为我在测试网上」是这里最贵的一种误解。

⚠️ 生产环境的 profile 应当**在视觉上可区分**(颜色/标记由用户自己设),而不是靠
读那一行小字。

## 3. 各形态的形状

### 3.1 内嵌 Web UI —— daemon 自带

```
┌──────────────────────────────────────────────────────────┐
│ ⬤ 本机 · 127.0.0.1:8548                    admin ▾      │ ← 同源,不可切
├────────────┬─────────────────────────────────────────────┤
│ 概览        │  待批准 3                                   │
│ 请求        │  ┌───────────────────────────────────────┐ │
│ 规则        │  │ 0x12…ab  转账 1.5 ETH   等待批准  [看]│ │
│ 签名者      │  └───────────────────────────────────────┘ │
│ 额度        │  今日花费  0.8 / 1.0 ETH  ████████░░       │
│ 审计        │                                            │
└────────────┴─────────────────────────────────────────────┘
```

⚠️ 顶栏仍然显示连的是谁 —— 即使不可切。用户需要知道自己在哪,而不是需要能换。

### 3.2 独立 Web UI —— ❌ 尚不存在

和内嵌**同一份代码**,区别只在于:后端地址来自 profile 而不是页面源。

⛔ 它需要 daemon 允许跨源访问,那是一个必须由 daemon 端显式开启的开关 ——
**默认关闭**。开着它意味着任意网页都能向这台 daemon 发请求。

### 3.3 TUI —— 终端 ⛔ **冻结的遗留形态**

⛔ **它不是和 Web UI 并列的第二个产品形态,不要再把它当成「另一种同样完整的用法」。**

| | |
|---|---|
| 状态 | **冻结**。代码保留在仓库里、仍然能跑、仍然收 bug 修复和安全修复 |
| 冻结于 | **2026-04-03**(`abc01e5`,最后一个给它加功能的提交) |
| 之后发生过什么 | `tui/` 只剩两类改动:**跟着后端接口变的被动适配**(单次 ≤10 行)和**全仓卫生**(gofmt / staticcheck / 覆盖率)。⚠️ 同一段时间里 `web/src` 有 **59** 次提交 |
| 功能齐全的壳 | **Web UI**。⛔ 新功能一律进 Web UI,终端界面**不接新功能** |
| 为什么还留着 | 它已经覆盖的那一片 —— **以读为主的运维流程**(看板、请求、规则、签名者、审计、指标)—— 现在仍然好用,而且它是纯终端环境里唯一能用的壳 |

```
┌ remote-signer ─ ⬤ 生产 · signer.example.com ─────────────┐
│ [1]概览 [2]请求 [3]规则 [4]签名者 [5]额度 [6]审计        │
├──────────────────────────────────────────────────────────┤
│  待批准 3                                                 │
│  › 0x12…ab   转账 1.5 ETH        等待批准                 │
│    0x34…cd   授权 USDC           等待批准                 │
├──────────────────────────────────────────────────────────┤
│ p 切换连接   ↑↓ 选择   ⏎ 详情   q 退出                    │
└──────────────────────────────────────────────────────────┘
```

⚠️ 这张草图画的是**没冻结的话它会长什么样**:`p 切换连接` 至今不存在,`-url` 和身份
每次启动都要重新给。⛔ 不要照着它去补终端界面的功能。

#### ⛔ 不做「换个框架把终端界面重写一遍」

> 决策记在 [`prd.md`](prd.md) §7 **D16**。这里记它的**具体形状**,免得六个月后
> 凭记忆重开一次同样的讨论。

| | |
|---|---|
| 结论 | 终端界面**只冻结,不重写**。用 Ink(React on terminal)之类重做一遍的方案**已否决** |
| 理由 | 这个产品交付成**一个静态可执行文件**:`CGO_ENABLED=0` 编译,运行镜像是 `debian:bookworm-slim`,里面**没有 Node** —— Node 只在构建阶段出现,用来打 Web UI。Ink 7 要求**运行时**有 Node 22+ |
| 代价 | 给「下载一个文件就能跑」加一个前置安装步骤,而且是加在**持有私钥的那个进程**旁边 |
| ⚠️ 这是**仓库约束**,不是框架偏好 | 换成任何「需要第二个运行时」的方案,结论都一样。⛔ 想重开这个话题,先回答:**这个二进制愿不愿意从此依赖第二个运行时?** |

构建与运行镜像见 [`../Dockerfile`](../Dockerfile) 与 [`deployment.md`](deployment.md)。

### 3.4 浏览器扩展 —— 给 dApp 用

它不是管理界面,是**注入到网页里的钱包**。dApp 发起签名,它转给 daemon。

```
┌────────────────────────────────┐
│ ⬤ 生产 · signer.example.com ▾ │ ← 点开切 profile
├────────────────────────────────┤
│ 当前账户                        │
│   0x7a3f…9c21      admin       │
│ 链   BSC (56)              ▾   │
├────────────────────────────────┤
│ ⏳ app.uniswap.org 正在请求签名 │
│    转账 100 USDT               │
│    [ 看规则怎么说 ]            │
└────────────────────────────────┘
```

⛔ 现状是**构建期写死**后端地址 —— 换一台 daemon 要重新构建扩展。这是四处缺口里
最该先补的:扩展是唯一一个普通用户天天用的壳。

### 3.5 桌面壳

包着内嵌 Web UI。⛔ 端口写死,同一台机器上跑两个 daemon 时连不上第二个。

---

## 4. 心智模型:三层,不要混

| 层 | 用户心里的问题 | 存在哪 |
|---|---|---|
| **连接** | 我在跟哪台机器说话? | 客户端(profile) |
| **身份** | 我是谁,能做什么? | daemon(成员 + 钥匙) |
| **授权** | 什么能被签,最多花多少? | daemon(规则 + 额度) |

⛔ **切连接不等于切身份**,虽然操作上常常一起换。⚠️ 同一个身份标识在两台 daemon 上
**可能是完全不同的两个身份** —— 「admin」只是个名字。所以 profile 必须成对记录
「地址 + 身份」,而不是让用户自己组合。

---

## 5. 要补的(按优先级)

- [ ] **profile**:纯客户端存储,记连接 + 身份,凭据加密且互相隔离
- [ ] **扩展支持运行时改后端** —— 现在要重新构建,而它是最常用的壳
- [ ] **顶栏常驻显示当前连接**,生产环境视觉可区分
- [ ] **桌面壳端口可配**
- [ ] **独立 Web UI**,以及 daemon 端默认关闭的跨源开关
- [ ] 便条过期(钥匙被吊销)时给明确拒绝,不是一串没权限(**N7**)
