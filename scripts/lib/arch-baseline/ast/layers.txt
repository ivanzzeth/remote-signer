# Clean Architecture 依赖方向的违规边(importing-pkg -> imported-pkg)。
# 由 cmd/archcheck 用 AST 读 import 得出;层的定义在 cmd/archcheck/layers.go。
#
# ⚠️ 这张表比 grep 版(gorm-outside-storage / core-imports-evm)大得多,不是因为
# 债变多了,是因为 grep 只能问「文件里有没有这个字符串」,AST 能问「这个包依赖了
# 哪个包」。grep 版看到 3 个文件,AST 看到 13 条边 —— 其中
# internal/api -> internal/config 那一整类(delivery 依赖组装根)grep 从来没报过。
#
# ⛔ 只许缩。⛔ 也不许通过放宽 layers.go 的 MayForward 让某条消失 ——
# 那是把尺子改短来让人变高。

internal/api/handler -> internal/config
internal/api/middleware -> internal/config
