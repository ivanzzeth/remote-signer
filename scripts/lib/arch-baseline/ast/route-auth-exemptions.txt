# 每一条**不带权限**的路由,一行一条:`<形状> <mux pattern>`。
#
# 形状只有三种,都由 internal/api/route_auth.go 的构造器产生:
#   public              无凭据可达,只套 SecurityHeaders
#   public-unwrapped    连 SecurityHeaders 都不套(只有 SPA 一条,理由见调用点)
#   authenticated-only  要有效 API key,但不要任何 permission
#
# ⛔ 这张表**不是**权限表,是「谁没有权限」的表。带权限的 55 条里的其余
# 路由**不在这里**,它们的权限就写在注册处。
#
# ---------- 为什么这张表会自己过期 ----------
#
# 三种腐烂方式,每一种都对应棘轮的一个方向,都是**红**:
#
#   1. 新增一条没权限的路由 → 基线里没有这个 key → 红
#   2. 路由被删了 → 基线里有一条对不上任何注册的 key → 红,把那行删掉
#   3. 路由**现在有权限了** → 同样对不上 → 红,把那行删掉
#
# ⭐ 第 3 条最容易被忽略,也最要紧:留着它,下一次那条路由**丢掉**权限时
# 这张表**不会**变红 —— 一条永远绿的豁免等于把检查关掉了。
#
# ---------- 理由在哪 ----------
#
# ⛔ 理由**不在这个文件里**,在注册那一行的 Public(...) / AuthenticatedOnly(...)
# 参数里 —— 那是改这条路由的人会读到的地方,而不是他要另外去找的地方。
# 门禁强制它非空(route-auth 这条硬规则),所以「没有理由的豁免」编译得过、
# 但过不了 make check。下面的注释只是索引,⛔ 不是权威。
#
# ---------- ⚠️ 这张表**证明不了**的事 ----------
#
# 一条前缀 pattern 背后可能有十几个端点,而它只能声明一个权限。
# `/api/v1/evm/rules/` 声明 PermListRules,handler/evm/rule.go:200-203 又在
# handler 里单独查 admin 才让 validate 过 —— 于是「每条路由都声明了权限」
# 今天就成立,而**逐端点的权限仍然是错的**。这张表数的是 pattern,
# 而 pattern 不是端点。要它真正到位,得先做 handler 拆解(提案 S3–S8);
# 在那之前它的价值是:拆解**新造**出来的每一条路由,出生时就得声明权限。
#
# ---------- 清单 ----------

# 首次启动引导:api_keys 表是空的,没有公钥可验签,要求鉴权就是死锁;
# 装好 admin key 之后 handler 自己回 410 关窗。
public GET /api/v1/bootstrap/status
public POST /api/v1/bootstrap/admin

# 存活探针,编排器和 `server status` 在任何 key 存在之前就要能问。
# ⚠️ 它回的不只是存活:还有版本 + 安全摘要(签名/自动锁超时、审计保留天数、
# approval guard 状态)。那是个信息披露问题,归端点的主人判,不归这条豁免判。
public GET /health

# Prometheus 抓取,文档明写无鉴权(docs/sdk-cli-matrix.md:30),TUI 指标视图也这么抓。
# ⚠️ middleware.PermReadMetrics 存在、授予了 admin+dev,却没有任何路由引用它 ——
# 要么那个权限是死的,要么这条豁免是错的。⛔ 只记录,不就地决定:
# 在这里加权限会静默打断每一个抓取端。
public /metrics

# SPA 本体 + catch-all。⛔ 是 public-unwrapped 而不是 public,因为
# SecurityHeadersMiddleware 会下 `Content-Security-Policy: default-src 'none'`,
# 那对 API 是对的,对它要发的 HTML/JS 是白屏。
public-unwrapped /

# /api/v1 的兜底,**不是一个资源**:任何别的 pattern 都不认领的 API 路径
# 由它回 JSON 404,免得落到 `/` 的 SPA catch-all 上、给一个在解析 JSON 的
# 客户端回 text/html(提案 §2.3 第 1 行)。⛔ 它没有权限可挂 —— 每个
# middleware.Perm* 都命名了「调用者可以做的某件事」,而走到这条路由意味着
# 它什么都做不了。
# ⚠️ 选 authenticated-only 而不是 public:今天这些路径本来就由 `/` 无凭据
# 提供,所以两种选法都不扩大暴露面;但 public 会在 Web UI 关掉或没装
# (SettingsManager 为 nil,`/` 根本不注册)的部署上留下一个无凭据的探针 ——
# 404 = 没有这条路由,401 = 有,等于把路由表白送。要 key 之后两者都是 401。
authenticated-only /api/v1/
