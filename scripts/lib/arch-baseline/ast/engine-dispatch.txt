# 调用方自己判断「这条规则用哪个引擎」的地方。
#
# 求值侧已经是干净的多态:RuleEvaluator 有 Type() + Evaluate(),进注册表,
# 加引擎不用改任何调用点。验证侧没做这一步,三个 validator 签名各不相同:
#   JSRuleValidator.ValidateRule(ctx, script, testCases)
#   SolidityRuleValidator.ValidateRule(ctx, rule)
#   MessagePatternRuleValidator.ValidateRule(ctx, rule)
# 于是每个调用方只能手写分支。
#
# 判据:一个文件点名 ≥2 个不同的 RuleTypeXxx 常量就是分发点。
# 点名 1 个是引擎在声明自己的 Type(),那是合法形状;常量声明处
# internal/core/types 豁免。
#
# ⛔ 收敛的方向是让引擎自己回答问题(RuleValidator 接口 + 注册表,
#    照抄 RuleEvaluator 那套),⛔ 永远不是删掉某个引擎。
#
